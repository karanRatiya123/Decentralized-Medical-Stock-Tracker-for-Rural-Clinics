The Decentralized Medical Stock Tracker for Rural Clinics is a web-based inventory management system developed to improve medicine stock monitoring and patient medicine tracking in Primary Health Centers (PHCs). The system helps reduce medicine shortages by providing automated low-stock and near-expiry alerts while maintaining accurate inventory records.

This project is built using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap.

🎯 Project Objective

The primary objective of this project is to develop an efficient medical inventory management system for rural healthcare centers that minimizes medicine shortages, improves stock visibility, and maintains patient medicine issue records through an easy-to-use web application.
